# 世界コンピュータ将棋選手権のアピール文書の要約

世界コンピュータ将棋選手権（WCSC）の第20回（2010年）から第36回（2026年）までの
アピール文書を、チームごとに1件のJSONへ要約したものである。過去の参加プログラムが
試したアイデアを手元に置き、次の実験や独自性の検討の材料にする。

**要約はAIが原文から作ったもので、人の目では検証していない**。誤読や取りこぼしが
あり得る。他チームの手法を根拠に何かを決めるとき、また外へ引用するときは、
各ファイルの `source_urls` から原文を読んで確かめる。文書の著作権は各チームにある。

## 中身

| 置き場 | 中身 |
|---|---|
| `wcscNN/<ディレクトリ名>.json` | 1チーム1回分の要約。ディレクトリ名は大会サイトの `appeal/` 以下の名前 |

889件、アイデアは2,774件ある。大会サイトで404だった4件と、全チームをまとめた
合本PDFは含めていない。第30回（2020年）は大会が中止になり、文書だけが提出された回である。

## 探し方

アイデアの横断検索は `jq` で行える。例として、進行度に触れたアイデアを回と名前つきで出す。

```
jq -r '.wcsc as $y | .software as $s | .ideas[]
  | select((.title + .description) | test("進行度"))
  | "\($y)\t\($s)\t\(.title)"' research/wcsc_appeals/*/*.json
```

同じチームの別の回は、`software` か `dir` の一致でたどれる。

## JSONの形

| フィールド | 中身 |
|---|---|
| `wcsc`・`year` | 大会の回と開催年 |
| `dir`・`team`・`software` | 大会サイトのディレクトリ名、チーム名、ソフト名 |
| `sources`・`source_urls` | 読んだ原文の相対パスとURL |
| `team_list_url` | その回の参加チーム一覧のURL |
| `summary` | チームの全体像を2〜3文で |
| `base` | 土台にした既存エンジン（`engine`）と評価関数（`eval_source`） |
| `eval`・`search` | 評価関数と探索の方式（`family`）と補足（`detail`） |
| `learning`・`hardware`・`language`・`claimed_strength` | 学習手法、計算資源、言語、棋力の主張 |
| `ideas` | 工夫を1件ずつ。下の表を参照 |
| `character` | エンタメ・コンセプト・個性のアピール |
| `notes` | 「前年と同じ」や、読めなかった部分の記録 |

`eval.family` は `手作り`・`線形`・`NNUE`・`DL`・`DL+NNUE`・`その他`・`不明` の
どれかになる。`search.family` は `αβ`・`MCTS`・`αβ+MCTS`・`その他`・`不明` のどれかになる。

`ideas` の各要素は次のフィールドを持つ。

| フィールド | 中身 |
|---|---|
| `category` | 16分類のどれか。評価関数、学習・教師データ、探索、詰み・終盤、入玉、定跡・序盤、時間管理、並列・分散、実装・高速化、ハードウェア、棋風・人間らしさ、エンタメ・演出、解説・人間支援、研究・実験的、開発手法・運用、その他 |
| `title`・`description` | 短い名前と、1〜3文の説明 |
| `originality` | `独自`・`既存手法の応用`・`再現・追従`・`不明`。判定は甘く、7割以上が `独自` になっている。参考程度に読む |
| `evidence` | 効果の主張（Elo・勝率など）。なければnull |
| `quote` | 原文の短い抜粋（100字以内） |

## 作り方

2026-10-16に、大会サイトの各回の参加チーム一覧（`team_list_url`）からアピール文書を
取得した。PDF・docx・テキストを文字へ変換し、画像だけの文書は画像として読んだ。
サブエージェント（Claude Sonnet）が回ごとに1チームずつ読み、上の形へ要約した。
取得した原本とテキストは、開発機の `data/raw/wcsc_appeals/` にある（gitの管理外）。

新しい回を足すときは、同じ形で `wcscNN/` を作る。
