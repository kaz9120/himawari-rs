訂正（2026-07-27）。直前の「実測の振れ幅は数百にとどまる」は誤りだった。
値域そのものは狭くない。深さ16での実測は次のとおりで、最大絶対値は
平衡点16384の近くまで届く。

| テーブル | 非ゼロ | 最大絶対値 | 非ゼロ平均 |
|---|---|---|---|
| main history | 785/2592（30.3%） | 14370 | 426.1 |
| continuation history | 16288/6718464（0.24%） | 14259 | 116.9 |

正しい原因は分布の偏りである。判定材料 `cont[0]+cont[1]` を413万回
集計したところ、52.4%が「ちょうど0」、つまり一度も更新されていない
組み合わせだった。

| 範囲 | 割合 |
|---|---|
| < -4000 | 0% |
| -4000〜-2000 | 0.012% |
| -2000〜-1000 | 0.14% |
| -1000〜-500 | 0.40% |
| -500〜0 | 34.1% |
| ちょうど0 | 52.4% |
| > 0 | 12.9% |

閾値 `-M×depth` を下回るのはM=500で0.28%、M=1000で0.081%、
M=2000で0.005%、M=4000で0%である。gravityが前提とする「同一エントリへ
何度も更新が来る」状況が、6.7Mエントリの疎なテーブルでは成り立たない。
1回の更新量が35では値が立たず、大多数のエントリが0付近に留まる。
やねうら王のmalus 2122は一度受けただけで閾値圏へ入る。

LMRの固定小数化とttPv項（2026-07-28、ADR-0076）。リダクションを1024倍の
固定小数にし、置換表のPVフラグでリダクションを弱める項を足した。

|---|---|
| 固定小数化 + ttPv項 | -43.8 [-74.9,-13.5]（470局、LLR -0.98で打ち切り） |

生じない等価変更である。

整数±1で試して-9.0だったのは、粒度が粗すぎたためと考えられる。

ADR-0074の機能検証は「変わったこと」を確かめる手順として定めたが、
「変わらないこと」の証明にも使える。等価リファクタの非劣性SPRTを
省ける場合がある。

```
bl   _bzero
```

構造体を値で組み立てると、LLVMが未初期化の配列を含むアグリゲートを
定数へ畳み、undefを0として具体化する。`#[inline]`でも変わらない。
`len`だけをポインタ経由で書く形にすると、bzeroはバイナリから消えた。

| 実装 | NPS | main比 |
|---|---|---|
| main（ゼロ埋めあり） | 1,279k | — |
| MaybeUninit（構造体を値で構築） | 1,282k | +0.5% |
| MaybeUninit（lenだけ書く） | 1,301k | +1.68% |
