# アイデア帳

ADRより手前の受け皿。1案1行で気軽に追記する。着手を決めたら
ADRを起草してこの帳から消す（採番と経緯はADR側に書く）。
棄却したら理由を1行残して ~~打ち消し~~ にする。
検証手段の略記: SPRT=対局ゲート、loss=検証損失、NPS=速度計測。
