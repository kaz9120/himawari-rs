# アイデア帳

ADRより手前の受け皿。1案1行で気軽に追記する。着手を決めたら
ADRを起草してこの帳から消す（採番と経緯はADR側に書く）。
棄却したら理由を1行残して ~~打ち消し~~ にする。
検証手段の略記: SPRT=対局ゲート、loss=検証損失、NPS=速度計測。

他の案を前提とする案は、メモ欄に依存先を書く。表の並び順は優先度を
表さない。ADR-0072はhistory pruningを単独で着手できると見なして失敗した。
着手前に依存を確かめる（[ADR-0074](adr/0074-feature-verification.md)）。

着手の選定は[ADR-0089](adr/0089-improvement-criteria.md)の3軸で行う。
速度（同じ探索木なら速いほうが強い）、ノード効率（同じPVなら少ない
ノードで到達するほうが深く読める）、終盤の正確さ（詰む詰まないを正確に
判断するほうが強い）である。どの軸に乗るかと、単独で効く仮説を書けない
候補は着手しない。ADR-0084は「他の項の前提になる」としか書けないまま
着手し、912局を使って中立だった。

**参照実装への追従（[ADR-0109](adr/0109-reference-parity.md)）は、この
帳の対象外である。** 2026-07-30に、やねうら王との機能差分をG0〜G10の
11群へ集約した。この帳に残っているのは、群に入らない独立した候補だけで
ある。群の内訳はADR-0109の付録にある。
