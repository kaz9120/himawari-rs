# 0176: 香の不成を2段目から3段目以降へ移す

- Status: accepted
- Date: 2026-08-18
- 関連ADR: [0017](0017-movegen-classes.md), [0074](0074-feature-verification.md), [0163](0163-sprt-hypothesis-choice.md), [0173](0173-knight-non-promotion-movegen.md), [0175](0175-sprt-until-decision.md)

## Context

[ADR-0173](0173-knight-non-promotion-movegen.md)で桂の不成を直したとき、香の
条件も参照実装と食い違っている疑いが出た。同ADRは「原典の該当行を自分で読んで
確かめていない」として保留した。

**オーナーの指摘で理屈のほうから決着した（2026-08-18）。**

> 香の不成、2段目は生成しなくて良いのだけど3段目は貫通する利きがあるので
> 生成した方が良いのですよね。

香の値打ちは前方へ貫通する利きにある。成香は金の動きなので前1マスへ縮む。
段ごとに不成の価値が変わる。

| 段（手番視点） | 不成の価値 |
|---|---|
| 3段目 | **高い。**香のまま貫通の利きが残る |
| 2段目 | 低い。不成だと1段目へしか行けず、横と後ろへ動ける成香に劣る |
| 1段目 | 行き所のない駒。非合法 |

現行の実装（`crates/core/src/movegen.rs:41-47`）は**ちょうど逆**である。

```rust
PieceType::LANCE => {
    if all { rel >= 1 } else { rel == 1 }   // rel==1 は2段目
}
```

通常探索では**2段目の不成だけ**を生成し、価値のある3段目以降を生成して
いない。[ADR-0017](0017-movegen-classes.md)の成り規約の表も
「2段目への不成は生成する（3段目以遠の成れる不成は生成しない）」と、
そのまま書いている。

## 実測（2026-08-18）

floodgate棋譜569局の全局面（74,966局面）で、敵陣への不成を段別に数えた。

| 駒 | 段 | 件数 | うち王手 |
|---|---|---|---|
| 香 | 2段目 | 2,051 | 24 |
| **香** | **3段目** | **3,393** | **188** |
| 桂 | 3段目 | 13,584 | 1,015 |

**現行は価値の低い2,051手を生成し、価値のある3,393手を捨てていた。**王手に
なる手で見ると24対188で、8倍近い開きがある。香の3段目不成が現れる局面は
3,225件（全体の4.3%）ある。

桂の13,584手は[ADR-0173](0173-knight-non-promotion-movegen.md)で解決済みで、
規模はその4分の1になる。

## Decision

**条件を `rel >= 2` へ移す。**

```rust
PieceType::LANCE => {
    if all { rel >= 1 } else { rel >= 2 }
}
```

`all = true`（検証・詰将棋用）は従来どおり2段目以降の全部を生成する。1段目は
行き所のない駒なので両方とも生成しない。

**採用の根拠は将棋の理屈である。**参照実装がどうしているかは補強材料に
すぎない。[ADR-0173](0173-knight-non-promotion-movegen.md)は参照との乖離を
主な根拠にしたが、本ADRは「香は貫通が値打ちで、成香は前1マスに縮む」という
駒の性質から決めている。**参照に無くても正しい変更はある。**

### SPRTの条件（着手時に確定。[ADR-0163](0163-sprt-hypothesis-choice.md)）

当初は**既定条件（elo0=0、elo1=5）**で始めた。[ADR-0173](0173-knight-non-promotion-movegen.md)が
同じ型の修正で+11.2 Eloを得ており、規模は4分の1でも棋力向上を主張する側で
測る根拠になると考えたためである。

**9,242局の時点で非劣性（elo0=−5、elo1=0）へ切り替えた（2026-08-19、オーナー判断）。**
[ADR-0163](0163-sprt-hypothesis-choice.md)は「対立仮説は着手時に決め、走行後に
変えない」「判定が出ないから緩める、は理由にならない」と定めているので、
変更の性質をはっきりさせておく。

- 切り替えの理由は**変更の位置づけの見直し**であって、判定が出ないからではない。
  香の3段目不成を落としていたのは指し手生成の欠陥であり、「強くなるから入れる」
  のではなく「バグなので直す。害がなければ入れる」が正しい枠だった。
  [ADR-0163](0163-sprt-hypothesis-choice.md)の分類でいう非劣性の側である
- 9,242局の時点で **+1.6 [−5.3, +8.5]** だった。既定条件の中点（約+2.5）を
  下回り、非劣性の中点（約−2.5）を上回る。**どちらの条件でも判定はまだ出て
  おらず、切り替えで有利な側へ寄せたわけではない**
- 記録を混ぜないため、棋譜を `adr0176-lance-noninf` へ引き継いで別名で回す
  （[ADR-0163](0163-sprt-hypothesis-choice.md)の運用）。既定条件の9,242局の
  ログも残す

**この切り替えは、着手時の分類を誤ったことの記録でもある。**[ADR-0173](0173-knight-non-promotion-movegen.md)に
引きずられて「棋力向上」と置いたが、実測の規模（手数で4分の1、王手になる手で
5分の1）からして既定条件では判定に届きにくい。**変更の性質から仮説を選ぶ**という
[ADR-0163](0163-sprt-hypothesis-choice.md)の原則を、着手時に十分適用できて
いなかった。

## 機能検証（2026-08-18。[ADR-0074](0074-feature-verification.md)）

固定深さ13で4局面のうち2局面のノード数が変わった。[ADR-0174](0174-mate1ply-knight-promotion.md)は
序盤の4局面で全部一致したが、本件は**序盤・中盤でも変化する。**香の3段目不成は
終盤に限らず現れる。

| 局面 | 変更前 | 変更後 | 変化 | 評価値 |
|---|---|---|---|---|
| 1 | 22,759 | 22,759 | +0% | cp 45 |
| 2 | 84,567 | 54,897 | −35% | cp 38 → cp −31 |
| 3 | 63,856 | 100,527 | +57% | cp 762 → cp 543 |
| 4 | 37,349 | 37,360 | +0% | cp −315 |

最善手は4局面とも変わらない。

## SPRT結果（2026-08-19）

**H1採択。+1.7 [−3.5, +6.9]、16,122局（8,061ペア）、LLR +3.01。**
W-D-Lは +7713 =776 -7633 である。非劣性（elo0=−5、elo1=0）で、既定条件から
切り替えた9,242局を引き継いだ通算の結果になる。

**害がないことを示す測り方として狙いどおりに収束した。**点推定+1.7は非劣性の
中点（約−2.5）を4.2上回っており、[ADR-0175](0175-sprt-until-decision.md)の
見積もり（真のEloが+2で7,466ペア）とも合う。実際は8,061ペアで判定に達した。

[ADR-0173](0173-knight-non-promotion-movegen.md)の+11.2とは桁が違う。手数で
4分の1、王手になる手で5分の1という事前の見積もりどおりで、**棋力向上ではなく
欠陥の修正として入れる**判断が数字とも合っていた。

[ADR-0175](0175-sprt-until-decision.md)の仕組みで最後まで自動で走った。上限で
止まって人が続行を判断する場面は一度もない。

## Consequences

- 通常探索の生成手数が入れ替わる。2,051手が消え、3,393手が増える。差し引き
  1,342手の増加で、[ADR-0173](0173-knight-non-promotion-movegen.md)の
  13,584手に比べれば小さい
- [ADR-0017](0017-movegen-classes.md)の成り規約の表を訂正する。香の欄は
  ADR-0173で桂を直したときに残していた
- **「参照実装との一致」を根拠にしない変更の前例になる。**[ADR-0155](0155-reference-walkthrough.md)が
  「参照にあるから正しいは棋力の根拠にならない」と記録したのと対になる。
  参照に無くても、駒の性質から説明できる変更は測る価値がある
