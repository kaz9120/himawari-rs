# 0191: floodgateの崩壊局面から盲点ベンチマークを作り、世代の定点観測にする

- Status: proposed
- Date: 2026-08-29
- 関連ADR: [0150](0150-rootstrap-evaluation.md), [0152](0152-floodgate-cycle.md), [0190](0190-selfplay-decided-thinning.md)

## Context

学習と検収の分布が閉じている。教師は自己対局、SPRTも同じ定跡集からの
自己対局で、**自分が作らない局面は学習と検収の両方から漏れる**
（2026-08-29オーナー指摘）。外の分布に触れるのはfloodgateだけである。

実戦では評価値が一手で300cp以上崩れることがある。崩壊の直前まで高い値を
出していた局面は、評価の盲点の記録そのものである。盲点は「実戦で到達
しうるのに教師で薄く、特徴の線形和で近似しにくい」領域に集中すると
考える（ADR-0190の被覆測定が背景。特徴の被覆93%に対し、入玉圏の質量は
1.7%しかない）。自己対局は自分の信念の外へ行かないので、この領域は
自然には埋まらない。異質な相手が掘った穴を回収する仕組みが要る。

基盤は揃っている。棋譜の回収は追記専用で決定論（ADR-0152）、評価値
系列からの大悪手検出は `kifu` ツールが持つ。足りないのは、検出した
局面を使い捨てのレポートで終わらせず、世代をまたいで追跡する器である。

## 選択肢と比較

### 案A: 追記専用の盲点ベンチマーク（採用）

崩壊局面を深い探索でラベルし、固定の測定集合として世代ごとに乖離を
測る。SPRTでは見えない分布外の劣化・改善が数字になる。

### 案B: 崩壊局面を教師データへ直接混ぜる

測定器を持たずに埋めると、効いたかどうかが分からない。混入は
ベンチマークで穴が定量化された後の充填手段として扱う（順序の問題）。

### 案C: 異種エンジンとのローカルガントレット

分布外の検収としては最も直接だが、外部エンジンの導入と整備が要る。
floodgateが同じ役を果たしているうちは見送り、ベンチマークで代える。

## Decision

案Aを採る。手順を固定する。

### 採取（決定論、追記専用）

- 入力は `data/raw/floodgate/` のCSA評価値系列（ADR-0152の資産）
- 自分の評価が次の自分の手番までに300cp以上落ちた対を崩壊とし、
  **崩壊前の自分の手番の局面**を盲点候補として抽出する
- 崩壊前の評価が0以上のものに限る。既に劣勢の局面が悪化を続けるのは
  自然な経過で、盲点の証拠にならない
- 処理順はファイル名・ply昇順で固定し、重複SFENは除く

母集団は起草時に評価値系列の走査で測った（869局、2026-08-29）。
崩壊対は3,142件あり、うち崩壊前が劣勢のものが2,498件を占める。床で
除いた後の候補は約650件で、勝勢（+2000以上）からの崩壊が373件、
互角〜優勢圏からが約270件になる。ベンチの初期規模として十分である。

### ラベルと確定

- 候補を1スレッド・固定1,000万ノードで再解析し、その値を正解ラベルと
  する（決定論。ADR-0152の分析と同じ流儀）
- 実戦時の評価と正解の乖離が勝率換算0.15以上のものだけをベンチへ入れる。
  乖離が小さい候補は「評価は正しく、水平線か相手の妙手」なので除く

### 測定と追跡

- 指標は、現行ネットの浅い評価（qsearch葉）と正解ラベルの勝率乖離の
  平均とする。クラス別（玉の段・進行度・駒割の符号）にも集計する
- ネットの昇格ごとに測り、推移を本ADRの測定節へ追記する
- **ゲートにはしない**。採否はSPRTが持つ（ADR-0150の教訓。代理指標を
  ゲートにすると指標へ過適合する）。これは分布外の検出器である

### 充填との接続

クラスの乖離が大きく件数も多い穴は、充填の対象になる。手段は外部
データの混合（入玉・tanuki 2024）、盲点クラス近傍の種局面からの
自己対局生成の2つで、充填後に同クラスの乖離が下がったかを次の回で
確認する。個別局面の暗記と区別するため、測定はクラス単位で読む。

### 運用の位置

`kifu cycle`（ADR-0152）へ組み込み、回収のたびに候補を追記する。
実験の待ち時間に回す作業として、CLAUDE.mdの待ち時間の使い方に
floodgate分析を加える（2026-08-29オーナー指示）。

## 測定台帳

### 初回構築（2026-08-29）

| 段階 | 結果 |
|---|---|
| 抽出 | 869局から候補644件（`blindspot extract`、決定論） |
| ラベル | 全644件を1,000万ノードで再解析（評価関数 `rl_g1b_reorder`） |
| 確定 | 勝率乖離0.15以上が498件（77%）。実戦で勝ち評価・正解は負けの符号反転が515件 |
| 実戦評価との乖離 | 中央値0.926。崩壊候補の大半は、ほぼ完全な誤評価の記録だった |

現行ネットの初回測定（`blindspot measure`）は次のとおり。

| 指標 | rl_g1b_reorder |
|---|---|
| 浅い評価と正解の勝率乖離（平均） | 0.109 |
| 同（中央値 / p90） | 0.040 / 0.295 |
| 実戦評価+501〜2000の帯（最悪クラス） | 0.207（105件） |

実戦時の乖離（中央値0.926）に対し現行ネットの浅い評価は0.040で、
大半の盲点は世代の改善で既に埋まっている。残る穴は優勢圏
（+501〜2000）に集中しており、充填の第一対象になる。

### 世代の推移

| ネット | 対象 | 乖離の平均 | 中央値 / p90 |
|---|---|---|---|
| rl_g1b_reorder | 498件 | 0.109 | 0.040 / 0.295 |
| pairrank_7860M_q1_reorder（教師移行後） | 521件 | 0.110 | 0.037 / 0.327 |

教師の総入れ替え（[ADR-0192](0192-tanuki2024-teacher.md)、+43.2）でも
分布外の乖離は横ばいで、劣化なしを確認した。ベンチ母集団は追記で
644→676件へ育っている。

方法上の限界も記録する。**正解ラベルは現行ネット自身の深い探索で
作っており、静的評価と探索が共有する盲点は検出できない**
（[ADR-0150](0150-rootstrap-evaluation.md)と同型の自己参照）。この
ベンチが測るのは「探索が見えるのに静的評価が見えないもの」に限る。
ネットが大きく世代交代したら、ラベルの作り直しを検討する（そのときは
新旧ラベルで乖離の推移を接続し直す）。

## Consequences

- ベンチマークの置き場が増える（`data/raw/blindspots/`、追記専用の
  SFEN＋ラベル）。gitignore対象で、生成は決定論なので再構築できる
- `kifu` ツールに抽出・ラベル・測定のサブコマンドが要る（実装は本ADRの
  acceptedと同じPRで行う）
- SPRT・floodgateレートに次ぐ第3の物差しができる。自己分布の外の
  性能が、世代の推移として初めて数字で残る
- 見直しの条件: 候補が集まらない（崩壊が稀）なら閾値を下げる。逆に
  ベンチが数千件を超えたら、クラス層化で間引いて測定コストを抑える
