# 0153: 優等・劣等局面の判定を探索経路内に限定する

- Status: proposed
- Date: 2026-08-09
- 関連ADR: [0026](0026-repetition.md), [0028](0028-pruning-extensions.md), [0109](0109-reference-parity.md), [0152](0152-floodgate-cycle.md)

## Context

floodgateの負け141局の全量解析（[ADR-0152](0152-floodgate-cycle.md)のkifuツール、
2026-08-09）で、最大級の逆転7件がすべて「評価+28000からの転落」だった。
典型はGokaku戦（`20260801100006`）で、203〜227手目に龍を8五↔8六で往復させ
ながら評価+28000を出し続け、実際の局面は−2000台だった。**優等局面の人工値が
探索を支配し、20手以上を浪費してから負けている。** 同型は6局にあった。

## 原因

`Position::repetition_state()`（[ADR-0026](0026-repetition.md)）は対局の
全履歴（`plies_from_null` の上限まで）を2plyずつ遡り、盤面一致・手駒非一致の
局面が見つかると無条件に `Superior` / `Inferior` を返す。探索は
`terminal_value` でこれを±28000にして即座に打ち切る。

**「大昔の同一盤面より手駒が多い」ことに戦略的な意味はない。** その昔の
局面が既に敗勢なら、それより優等でも敗勢のままである。Gokaku戦では
序盤に現れた盤面と同じ配置へ終盤に戻り、手駒だけ増えていたため、
実際は−2000の局面で+28000が返り続けた。

## 参照実装の扱い

やねうら王（現行）は同じ罠を明示的に避けている。

- do_moveで千日手情報を前計算し、探索は `st->repetition && st->repetition < ply`
  のときだけ返す。**同一局面の両方の出現が探索経路内（root以後）にあるとき
  だけ**判定が有効になる
- 例外は4回目の同一局面（強制千日手）のみ。`repetition` を負値にして
  plyに関係なく成立させる
- 優等・劣等については探索部にコメントで理由が書かれている。
  「優等局面・劣等局面はrootより遡って判定しない。USIで出力する評価値が
  VALUE_SUPERIORになるのはちょっと嫌だし、優等局面に突入するからと言って
  即詰みを逃がすのもちょっと嫌」（yaneuraou-search.cpp、issue #264参照）

探索経路内の優等・劣等は「この探索の中で同じ盤面に手得で戻れる」という
意味を持つので、判定として正しい。rootを跨いだ比較だけが無意味になる。

## Decision

`repetition_state` へ探索plyを渡し、`Superior` / `Inferior` は検出距離
`i < ply` のときだけ返す。`Draw`（および連続王手のWin/Lose）は現行どおり
全履歴を対象にする。通常の千日手は対局ルールそのもので、履歴との一致にも
意味があるからである（4回目の強制成立を待たず1回目で引き分け値を返す現行の
割り切りも[ADR-0026](0026-repetition.md)のまま変えない）。

参照実装のdo_move前計算（`st->repetition` 方式）への全面追従は今回やらない。
害が出ているのは優等・劣等のroot跨ぎだけで、前計算は性能最適化の色が濃い。
効果が残るようなら別ADRで追従する。

## 検証

- 機能検証はノード数が変わる（挙動を変える修正なので当然）。ADR-0074の
  枠ではなく棋力向上としてSPRT既定条件にかける
- kifuツールでGokaku戦を再解析し、+28000の出力が消えることを確認する
- 単体テスト: 探索経路内の優等は返る、root跨ぎの優等は返らない、
  全履歴のDrawは従来どおり返る

## Consequences

- 優等局面の人工値がUSIのinfoへ漏れる問題（レポートの+28000表示）も同時に
  解消する
- 実戦で優等往復に吸い込まれて時間と手を浪費する型（6局で確認）が消える
- SPRTでH1に届かない場合でも、参照実装と同じ構造への整列かつ実害の記録が
  あるため、非劣性（elo0=-5, elo1=0）へ落として取り込む判断がありうる。
  その場合は判断をこのADRに追記する
