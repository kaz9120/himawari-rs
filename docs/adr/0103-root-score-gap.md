# 0103: rootの1位2位差を打ち切りの判定材料に足す案（実装前に棄却）

- Status: rejected
- Date: 2026-07-29
- 関連ADR: [0059](0059-easy-move-scaling.md), [0089](0089-improvement-criteria.md), [0032](0032-multipv.md), [0102](0102-move-horizon.md)

## Context

[ADR-0102](0102-move-horizon.md)で時間配分を一律に薄くして-107.2 Eloを
出した。そのとき副産物として、打ち切りの余地を測っている。

30+1の自己対局160手で、1手ごとに「最終的な最善手が確定した深さ」を
測った結果は次のとおり。

| 指標 | 値 |
|---|---|
| 最善手が確定した深さの中央値 | 1 |
| 到達深さの中央値 | 17 |
| 最善手が確定して以降に使った時間 | 総消費の78.6% |
| 深さ1の手がそのまま最終手だった手 | 132手（82%） |

削る余地は大きい。ただしADR-0102が示したとおり、一律に削ると最善手が
後で変わる局面から時間を奪って負ける。**削ってよい局面の見分けが
要る**。

現行の見分けは[ADR-0059](0059-easy-move-scaling.md)の3係数（評価の
下落・最善手の連続不変回数・ノード集中度）で、積を `optimum` に掛ける。
[ROADMAP.md](../ROADMAP.md)の教訓は「判定材料の精度を上げると効く」で
あり、材料を1つ足す案を検討した。

候補は「rootの1位と2位のスコア差」である。差が大きい局面は実質的に
選択肢がなく、いくら読んでも結論が変わらない。オーナーが指摘した
「取る一手なのに時間を使っている」局面を直接捉える指標でもある。

[ADR-0059](0059-easy-move-scaling.md)は同じ案を案Cとして検討し、
「MultiPVを内部的に2に上げるとノード数が増え、時間短縮の利得を
打ち消す」として退けている。しかしMultiPV=1でも、rootでfail lowした
手の探索値は無料で取れる。null window探索の返り値は真の値の上界なので、
1位との差は真の差の下限になる。前提が変わったため測り直した。

## 測定

`HIMAWARI_ROOT_GAP` を設定したときだけ判定材料を標準エラーへ出す
計測ビルドを作り、直近SPRTの棋譜（`data/sprt/adr0101.jsonl`）から
抽出した局面で測った。深さ8の1位が深さ16でも最善のままかを
「不変」とする。

### 単独では信号がある

まずMultiPV=2の正確なスコアで測った（110件）。

| 1位2位差 | 件数 | 不変率 |
|---|---|---|
| 50cp未満 | 49 | 34.7% |
| 50cp以上 | 61 | 67.2% |

差は+32.5pp（z=3.6）。次に実装で得られるfail-lowの上界で測った
（119件）。

| 1位2位差（上界） | 件数 | 不変率 |
|---|---|---|
| 50cp未満 | 88 | 52.3% |
| 50cp以上 | 31 | 74.2% |

差は+21.9pp（z=2.3）。上界を使うと差が小さく出る側へ寄るが、信号は
残った。別の抽出（139件）でも+18.9ppで再現している。

### 既存の判定材料で条件づけると消える

問題はここからである。既存の3係数の積（`scale`）で層別した（139件）。

| 層 | 1位2位差 | 件数 | 不変率 |
|---|---|---|---|
| scale < 0.8（既存が縮めると判断） | 50cp未満 | 49 | 65.3% |
| scale < 0.8 | 50cp以上 | 16 | 68.8% |
| scale ≥ 0.8（既存が縮めないと判断） | 50cp未満 | 69 | 43.5% |
| scale ≥ 0.8 | 50cp以上 | **5** | 80.0% |

既存が「縮める」と判断済みの層では、1位2位差で分けても+3.5ppしか
違わない。**この層で新しい情報を持っていない**。

差が残るのは「既存が縮めないと判断し、かつ1位2位差が大きい」層だけ
だが、**該当は139件中5件（3.6%）**で、比率を論じられる数ではない。

### 既存の3係数は十分に効いている

同じデータで既存の指標そのものを見ると、きれいに並んでいる。

| scale（既存3係数の積） | 件数 | 不変率 |
|---|---|---|
| 1.00以上（時間を伸ばす） | 44 | 38.6% |
| 0.70〜1.00 | 45 | 57.8% |
| 0.70未満（強く縮める） | 50 | 68.0% |

伸ばすと判断した局面ほど実際に最善手が変わりやすい。ノード集中度
単独でも 44.6% / 74.3% / 66.7% と分かれる。1位2位差の単独の信号は、
その大半がこれらと重複していた。

## Decision

着手しない。

[ADR-0089](0089-improvement-criteria.md)は「単独で効く仮説を書けない
候補は着手しない」と定めている。1位2位差は単独では信号を持つが、
**既存の判定材料に対して独立な情報をほとんど持たない**。効く可能性が
残るのは全体の3.6%の層だけで、そこも5件しか観測がない。

[ADR-0084](0084-lmr-cutnode.md)は構造的な理由だけで着手して912局を
使い、-1.1の中立で終わった。同じ形になる公算が高い。測定に要した
時間は40分で、912局より安い。

## Consequences

- 打ち切りの判定材料を1つ足す方向は、少なくとも1位2位差では伸びない。
  [ROADMAPの候補](../ROADMAP.md#候補)から候補を落とす
- 現行の3係数は、この測定の範囲では十分に機能している。ノード集中度が
  1位2位差とほぼ同じものを測っているためと考えられる。どちらも
  「1つの手が突出しているか」を別の角度から見ている
- 残る余地は、既存の材料の言い換えではなく新しい情報源にある。
  候補は2つある
  - intra-iterationの情報。rootのfail-lowが起きた事実は、イテレーション
    完了を待つ `falling` より早い
  - 評価関数の多ヘッド化（WDL・進行度・安定度。ADR索引のバックログ）
- 「既存が縮めないと判断し、かつ1位2位差が大きい」層は未決着のまま
  残す。観測を40件ほどまで増やせば判断できるが、対象が全体の3.6%
  なので、得られる効果は測定コストに見合いにくい
- rootでfail lowした手の値を記録する実装は捨てた。使い道が残るとすれば
  root手を前回スコアで並べ替える案（ノード効率の軸）で、そのときに
  作り直す
