# 0216: 攻撃的な受けの局面を3倍に重くして学習し、盲点が埋まるかを測る

- Status: proposed
- Date: 2026-09-18
- 関連ADR: [0129](0129-auxiliary-heads.md), [0133](0133-effect-pretraining.md), [0185](0185-sibling-ranking-loss.md), [0190](0190-selfplay-decided-thinning.md), [0197](0197-hard-negatives.md), [0210](0210-teacher-mix-control.md), [0212](0212-tanuki-bench-mix.md), [0213](0213-freeze-structure-focus.md)

## Context

[ADR-0213](0213-freeze-structure-focus.md)の測定で2つ分かった。現行ネットは
攻撃的な受け（相手の攻め駒に当てる手）を見えていない。教師データの9.0%が
この型で、最善手の静的評価の順位は一般より+1.08悪く、最良の葉との差
（平均損）も127cp大きい。一方、FTの構造は焦点を52%まで表せるのに、
評価値で学習した現行FTは42%で止まる。壁は容量ではなく、目的関数が
焦点を要求していないことにある。

学習側の介入の候補を3つ検討し、2つは先例で閉じている。

- 補助の的（焦点の熱地図）を評価値と同時に学習する案。補助ヘッドの
  同時学習は[ADR-0129](0129-auxiliary-heads.md)で−310、事前学習は
  [ADR-0133](0133-effect-pretraining.md)で−0.001だった。利きを正確に当てる
  FTを作っても下流に効かなかった。熱地図は「次に駒が動くマス」で、
  ADR-0129が壊した指し手予測に近い
- ランキング損失の負例を焦点で選ぶ案。[ADR-0197](0197-hard-negatives.md)が
  負例の選び方の線を閉じた。難しい負例はdepth 9の教師より良い手を含み、
  矛盾した制約になって回帰を歪める。焦点で選んだ負例も同じ危険を持つ

残るのは、**盲点の型の局面そのものを重く学習させる**案である。損失の
形も負例の引き方も変えず、教師のラベルもそのまま使う。該当局面の平均損は
127cp大きい。この型は難しく、学習が足りていない兆候である。勾配の
配分を増やす手当てが素直に当たる。

## 仮説

**攻撃的な受けの局面を3倍に重くして学習すると、その型の最善手の順位が
一般に近づき、対局でも強くなる**。

## 測定の設計

### 動かす変数

該当局面の重みだけを動かす。重みは複製で与える。該当局面を2回余分に
書き足して3倍にし、全体をシャッフルしてから静止化する。損失の重み付けでは
なく複製にするのは、学習器を変えずに済み、静止化と兄弟群の経路も
そのまま使えるためである。

| 群 | 学習データ | 局面数 |
|---|---|---|
| 統制 `tdef_ctrl_300M` | 生データの先頭3億をシャッフルし静止化したもの | 3.0億 |
| 処置 `tdef3_300M` | 同じ3億に、該当局面（約9%）を2回ずつ書き足す | 約3.54億 |

処置は局面数が18%増える。量の効果は[ADR-0212](0212-tanuki-bench-mix.md)の
量の統制（tanukiを6,000万足す `tmix_t60_300M`、+20%）が、同じtanukiの
3億の測定台で測る。元のデータは違うが同じ系列・同じ規模なので、その値を
参考に差し引いて読む。[ADR-0210](0210-teacher-mix-control.md)では
haoの測定台で同じ系列の+20%は−11.6だった。

### 固定するもの

- 該当の判定は `hmwr diag defend` と同じ。教師の最善手を指した後の局面で、
  動いた駒が利く相手の駒のうち、自玉の周囲8マスへ利くものがあれば該当。
  判定には静止化前の局面と教師手が要るので、複製は静止化の前に行う
- 統制と処置は同じ静止化前の3億から作る。シャッフルの種と静止化の設定
  （1手、並列8）は両群で同じにする
- 学習のレシピはADR-0212と同じ。ゼロから1エポック、batch 16384、peak_lr 1e-3、
  λ0.7、seed 0、兄弟群 `rank_tanuki_210M`、検証 `valid_tanuki_q1`
- 対局の条件もADR-0212と同じ。ビルド `adr0200-himawari`、10+0.1、hash 64、
  並列8、裁定2000,8、最大400手、1,000ペア。統制との1本
- 盲点の再測定。処置のネットで `hmwr diag defend` を同じ50万局面に当て、
  該当群と一般群の平均順位の差を取る

### 読み方の事前登録

対統制のEloをD、ADR-0212の量の統制のEloをAと書く。「効いた」はD−Aが+15以上で、
Dの95%区間の下端が0を超えることとする。順位の差は、現行の+1.08が
+0.5以下へ縮めば「埋まった」とする。

| Elo | 順位の差 | 読み | 次の一手 |
|---|---|---|---|
| 効いた | 埋まった | 盲点は学習不足で、重くすれば埋まり、棋力に変わる | 本学習（78.5億）へ複製を入れる設計を次のADRで書く。倍率を振るのはその後 |
| 効いた | 埋まらない | 強くなった理由は別にある | 量の効果を疑い、Aと並べて読み直す。順位の差は診断として残す |
| 効かない | 埋まった | 型は学習できるが、棋力には変わらない | この線を閉じる。盲点の指標は棋力の代理にならないと記録する |
| 効かない | 埋まらない | 3倍では足りないか、型の定義が粗い | 閉じる。倍率を上げる前に、該当の定義を焦点の熱地図で置き換える案を検討する |
| 有意に負 | 問わず | 分布の偏りが害になった（[ADR-0190](0190-selfplay-decided-thinning.md)の型） | 閉じる |

## 実行

### 道具

`psv oversample --in <psv> --out <psv> --kind defense --times 3` を足す。
静止化前のpsvを読み、該当局面を末尾に（times−1）回書き足す。判定は
`psv defend` の `is_aggressive_defense` を共有する。`hmwr data oversample
<出力名> --in <入力名> --kind defense --times 3` で包む。

### 手順

specは `experiments/adr0216-defense-oversample.toml`。静止化前の3億は
残っていない（`train_7860M_q1` は静止化済みで、元のシャッフル出力は消費
済み）。`data/raw/tanuki2024/` の生データ（対局順、10億局面のファイル）の
先頭3億をシャッフルして元にし、統制もそこから作り直す。統制は
[ADR-0212](0212-tanuki-bench-mix.md)の `tbase_300M` ではなく、この元から
静止化した `tdef_ctrl_300M` になる。量の統制は同じ元ではないので、
ADR-0212の値を参考として並べるにとどめる。

生データの先頭3億をシャッフル→複製→シャッフル→静止化→学習→対局→盲点の
再測定の順に走る。静止化は2本で最大2時間、学習は2本で約4.5時間、対局は
約2時間かかる。

## Consequences

- 効いた場合、本学習の教師に該当局面の複製が入る。78.5億の9%を2回足すと
  約14億増え、学習が約9時間延びる
- 効かなくても、「盲点の型を重くする」線の結果が残る。焦点の熱地図で
  該当の定義を置き換える案は、その結果を見てから決める
- `psv oversample` は他の型（入玉、詰みの周辺）にも使える。`--kind` を
  足すだけで、ADR-0206のような混合の実験を局面の型で切れる
