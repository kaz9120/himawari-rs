# 0173: 桂の3段目不成を通常の指し手生成でも出す

- Status: accepted
- Date: 2026-08-17
- 関連ADR: [0017](0017-movegen-classes.md), [0028](0028-pruning-extensions.md), [0074](0074-feature-verification.md), [0109](0109-reference-parity.md), [0139](0139-mate1ply-in-search-retry.md), [0152](0152-floodgate-cycle.md), [0163](0163-sprt-hypothesis-choice.md)

## Context

オーナーから実戦の観察が出た（2026-08-17）。「詰みの見逃しが多い。Mateが
出るときは良いが、ダメなときは3手詰めも見逃す。桂馬が絡む詰みを見落としているのでは
ないか。詰ます手がカットされて読まれていないのではないか」の3点である。

floodgateの棋譜569局（2026-07-31〜08-17、[ADR-0152](0152-floodgate-cycle.md)の
回収）で裏を取った。CSAには実戦時の評価値が `'** <値> <PV>` として残っている
（先手視点。負け局の最終値の符号で検証した）。

負け267局のうち、**「自分の手番で+1000以上 → 次の自分の手番で投了級」の崩壊が
14局**あった。そのきっかけになった相手の手の駒種が偏っている。

| 駒種 | 件数 |
|---|---|
| **桂の跳ね** | **11局（79%）** |
| 香・馬・角 | 各1局 |

対照群では桂は埋もれる。負け局全体で相手の最終3手に現れる桂は7.1%、自分が
勝った局の最終3手では上位6位圏外である（金24.0%・龍14.7%・銀12.0%）。
二項検定（n=14、k=11、ベースレート0.071）で**片側p値 6.9e-11**。崩壊の閾値を
+500〜+1500へ振っても桂の比率は77〜79%で動かない。

全569局で「相手が駒Xを指した直後に自分の評価値がどれだけ下がるか」を測った。
**3000以上の急落を起こすのは桂（0.29%）と成桂（0.23%）だけで、他の11駒種は
いずれも0.00%**だった。

## 原因

`crates/core/src/movegen.rs` の成り規約で、桂の不成が全生成フラグに
条件付けられていた。

```rust
PieceType::KNIGHT => all && rel >= 2,
```

`all` は検証・詰将棋用のモードである。MovePickerは3か所すべてで `all = false`
を渡す（`movepick.rs:789`・`806`・`821`）。したがって**通常探索は桂の不成を
1手も生成しない。**

問題になるのは「成ると王手にならないが、不成なら王手になる」形である。成桂は
金の動きなので、桂とは利きが違う。実戦（2026-08-16 vs Daigoro-20171029）の
104手目がその形だった。

- 6七の**桂**（不成）は5九・7九へ利く → **5九の先手玉に王手**
- 6七の**成桂**は5八・6八・7八・5七・7七・6六へ利く → **5九には利かない**

探索は成る手だけを読み、「王手にならない」と判断して切り上げる。実戦では
不成で王手され、詰む。

`genchk` で104手目の生成を数えた。探索の生成は112手、全合法手は117手で、
**漏れた5手のうち2手が王手、そのうち1手が実戦の詰ます手**だった。

```
探索から漏れる手: 5件
  2f2g
  5e4g  ←王手
  5e6g  ←王手     ← 実戦でトドメを刺した手
  6e5g
  6e7g
```

**枝刈りで刈られていたのではない。手として生成されていなかった。**
1手前で2,700万ノード読んでも見つからないのは当然である。

枝刈り側も個別に無効化して確かめた。movecount pruningを実質無効化しても、
王手をSEE枝刈りの対象から外しても、評価値は+4177→+3101と動くだけで詰みは
出ない。**手が存在しないので当然である。**

## 参照実装の扱い

やねうら王とAperyはどちらも桂の不成を全生成フラグで条件付けない。

- やねうら王 `source/movegen.cpp` の `make_move_target`。KNIGHTの不成分岐だけ
  `All &&` のガードがない。`movegen.h` の `LEGAL` の注記も「2段目の歩・香の
  不成や角・飛の不成は生成しない」で、**桂は除外リストに入っていない**
- Apery `src/generateMoves.cpp` の `GeneratePieceMoves<MT, Knight, US, ALL>`。
  同じく `ALL` のガードがない

**本エンジンだけが桂の不成を落としていた。**[ADR-0109](0109-reference-parity.md)の
参照追従で拾えなかった乖離である。

[ADR-0017](0017-movegen-classes.md)の成り規約は桂を「成れるときは成りのみ
（1・2段目の不成は行き所がなく元々非合法）」と書くが、この理由は3段目を
説明していない。3段目の桂不成は合法で、しかも実戦で決め手になる。

## 選択肢と比較

### 案A: 桂の不成を通常生成でも常に出す

`all &&` を外して `rel >= 2` だけにする。1語の削除で、参照2実装と一致する。
1〜2段目は不成だと行き所のない駒になるので `rel >= 2` は残す。

コストは終盤の生成手数の微増である。実戦569局の終盤22,624局面で、通常生成
では作れない王手（成りで代替できないもの）を持つ局面は318（1.41%）だった。

### 案B: 王手になる桂の不成だけを出す

手数の増加を抑えられるが、生成のたびに `gives_check` の判定が入る。生成は
探索のホットパスなので、1.41%のために全局面へ判定を足すのは割に合わない。
参照実装にも対応物がない。

### 案C: mate_1plyの通常探索への組み込みで代替する

[ADR-0139](0139-mate1ply-in-search-retry.md)が−23.4 Eloで棄却済みである。
加えて今回の崩壊は5手以上の詰みで、1手詰め判定では届かない。実測でも
Daigoro戦の103手目・104手目に1手詰めと3手詰めは存在せず、詰みは108手目に
成立した。

## Decision

**案Aを採る。**決め手は、参照2実装が条件付けていない箇所であること、そして
実戦の敗着11局が例外なくこの形だったことである。

修正後に崩壊11局を深さ14で測り直すと、**11局すべてで評価の符号が反転し、
6局で即詰みを検出する。**

### SPRTの条件（着手時に確定。[ADR-0163](0163-sprt-hypothesis-choice.md)）

**既定条件（elo0=0、elo1=5、`--tc 10+0.1 --concurrency 8 --adjudicate 2000,8`）
で測る。**棋力向上を主張する側を採る根拠は、実戦で11局の敗着に直結している
ことである。判定に至らなければ[ADR-0087](0087-sprt-resume.md)の `--resume` で
局数を積み、条件は変えない。

**発現しにくい条件である点は先に書いておく。**該当する王手を持つ局面は終盤の
1.41%で、詰まされる局面1,078のうち通常生成では検出できないのは14（1.3%）
だった。10+0.1は対局が短く、裁定（2000cp×8手）も終盤前に打ち切るので、
[ADR-0153](0153-superior-repetition-root-gate.md)と同じ「既定条件で測れない変更」に
なる可能性がある。そうなった場合の判断は本ADRへ追記する。

## 機能検証（2026-08-17。[ADR-0074](0074-feature-verification.md)）

固定深さ13でノード数を比べた。4局面のうち3局面で変わり、探索に影響している
ことを確認した。局面2は評価の符号が変わり、局面4は最善手も変わった。

| 局面 | 変更前 | 変更後 | 変化 | 評価値 |
|---|---|---|---|---|
| 1 | 22,759 | 22,759 | +0% | cp 45 |
| 2 | 49,339 | 84,567 | +71% | cp −43 → cp +38 |
| 3 | 60,637 | 63,856 | +5% | cp 604 → cp 762 |
| 4 | 33,391 | 37,349 | +12% | cp −338 → cp −315（最善手も変化） |

NPSは深さ19・3周の交互測定で **+5.09%** だった（1,597,216 → 1,678,530）。

| バイナリ | NPS（3周の平均） | 比 |
|---|---|---|
| base-adr0173-knight | 1,597,216 | — |
| cand-adr0173-knight | 1,678,530 | +5.09% |

**この数字は解釈しない。**生成手数が増えるのに速くなる理由を説明できていない。
ベンチ局面は序盤・中盤で、桂の3段目不成が関わる場面は少ない。同じ深さで
ノード数も +1.2% 動いている（2,113,574 → 2,138,417）ので、探索木が変わった
副作用と見て測定値のまま残す。**速度改善を主張する根拠には使わない。**

## SPRT結果（2026-08-17）

**H1採択。+11.2 Elo [+3.7, +18.8]、7,674局（3,837ペア）、LLR +2.92。**
W-D-Lは +3819 =284 -3571 である。

既定条件（elo0=0、elo1=5、`--tc 10+0.1 --concurrency 8 --adjudicate 2000,8`）
で測った。着手時に決めた条件のまま変えていない。

最初の3,000ペアでは判定に至らなかった（+7.6 [−1.0, +16.2]、LLR +1.32）。
[ADR-0087](0087-sprt-resume.md)の `--resume` で上限を8,000ペアへ広げて積み、
3,837ペアでH1に達した。**条件を緩めずに局数で解決した例である。**

着手時に「10+0.1では発現しにくい可能性がある」と書いたが、外れた。該当する
王手を持つ局面は終盤の1.41%しかないのに、既定条件で+11.2が出ている。
**頻度の低さは効果の小ささを意味しない。**詰みを見落とす局面は、そのまま
勝敗が決まる局面だからである。

## Consequences

- 探索の生成手数が終盤で微増する。NPSへの影響は機能検証で測る
- 実戦で頓死の型が1つ消える。負け267局のうち14局（5.2%）が崩壊で、その11局が
  この形だった。全部拾えれば勝率51.5%→54.0%、レート換算で約+17に相当する
- [ADR-0017](0017-movegen-classes.md)の成り規約の表を訂正する。桂の記述が
  3段目を説明していない
- **香の不成の条件も参照と食い違っている可能性がある。**現行
  （`movegen.rs:41-47`）は通常生成で2段目の不成**だけ**を出し、3段目以降を
  出さない。参照が逆（3段目以降を常に出し、2段目だけ `All` 扱い）だという
  報告があるが、原典の該当行を自分で読んで確かめていない。実測の影響は20手
  （桂の416手に対して小さい）なので、**本ADRでは触らない。**確認してから
  別ADRで扱う
- 詰み見逃しには別経路も残る。floodgate棋譜から抽出した2045局面を「詰み手数ちょうどの深さ」で探索すると、
  5手詰めの検出率は62.7%になる（全幅なら100%）。TT-ProbCut
  （`search.rs:1779-1787`）を切ると78.7%へ戻る。**本ADRの修正とは
  独立なので、別ADRで測る**
