# 0224: 付け直し済みの20億から1億を選び、選び方で棋力が変わるかを測る

- Status: proposed
- Date: 2026-10-05
- 関連ADR: [0136](0136-quiet-teacher-positions.md), [0160](0160-revisit-rejected-under-better-eval.md), [0190](0190-selfplay-decided-thinning.md), [0214](0214-epochs-bench.md), [0215](0215-dl-relabel-pilot.md), [0216](0216-defense-oversample.md), [0219](0219-relabel-2b-in-place.md)

## Context

[ADR-0219](0219-relabel-2b-in-place.md)で、dlshogiのラベルの20億がtanukiのラベルの
78.5億に+67.9で勝った。ラベルの質は、4倍の量に勝る。局面とラベルを切り離して
扱えるようになったので、次は「どの局面にラベルの予算を使うか」を問う
（オーナーとの議論、2026-10-04）。ラベルの付け直しは1局面ごとに費用がかかる。
選び方で同じ局面数から棋力を引き出せるなら、付け直しの費用がそのまま浮く。

付け直し済みの20億（`train_7860M_q1` の先頭20億）は、tanuki 2024の78.5億を
全体シャッフルした先頭である。全体からの一様な無作為標本になっている。
その性質を測った（2026-10-04〜05）。

- 盤面の重複。先頭1億で7.67%、先頭5億で10.53%が、すでに出た盤面の繰り返しだった。
  集合が大きいほど割合が増える。5億の中で最多の盤面は200,366回現れる。
  dlshogiの推論は決定的なので、重複した局面には同じラベルが付く
- 決着圏の多さ。dlshogiの勝率で10%未満か90%超の局面が47.3%ある。勝率1%未満か
  99%超だけで30.9%になる（先頭1,000万局面）

どちらも、ラベルの予算の大きな割合を占める。この20億から1億を選ぶだけなら、
付け直しの費用はかからない。学習1本0.6時間、対局1本1.9時間で1条件を測れる
（[ADR-0215](0215-dl-relabel-pilot.md)の実績）。1億の測定は20億へ持ち越せた
（[ADR-0215](0215-dl-relabel-pilot.md)の+99.4が、[ADR-0219](0219-relabel-2b-in-place.md)で+113.0）。

### 決着圏の間引きを再訪する理由

[ADR-0190](0190-selfplay-decided-thinning.md)は決着圏の間引きを−12.2で棄却し、
「事後の分布整形の方向はここで打ち切る」とした。本ADRは同じ介入を測り直す。
理由は3つある。

1. 当時の測定には交絡があった。継続学習の窓を間引いたので、学習の総移動量が
   24%減り、検証集合も変わった。−12.2の帰属は「間引き・移動量・選択基準の合成」
   以上に絞れないと、ADR-0190自身が書いている
2. 本ADRは局面数（1億）・ステップ数・検証集合を固定する。ゼロから学習するので、
   間引きの効果だけを分けて測れる
3. ラベルが変わった。当時は自己生成の深さ8のラベル、今回はdlshogiのラベルである。
   より良い評価で棄却を見直す手順は[ADR-0160](0160-revisit-rejected-under-better-eval.md)にある

## 仮説

**同じ1億局面でも、選び方を変えると棋力が変わる**。

処置ごとの見込みは次のとおり。

- 重複の除去。同じ1億で、異なる局面が7.67%増える。効きは小さい見込みで、
  ±15の測定幅で検出できない可能性が高い。費用の面で意味がある。付け直しの前に
  重複を除けば、その分のラベル付けが要らない
- 決着圏の間引き。決着圏の割合を47.3%から18.3%へ下げる。勝負のついた局面の
  評価はどの手でもほぼ同じで、教えられることが少ないと考える。浮いた枠は、
  形勢の揺れる局面に回る

## 測定の設計

### 動かす変数

1億の選び方だけを動かす。どの群も `train_7860M_q1` の先頭から読み、1億で打ち切る。

| 群 | 選び方 | 作り方 | 読む範囲 |
|---|---|---|---|
| 統制 `sel_ctrl` | 先頭1億をそのまま | `hmwr data split --count 100000000` | 1億 |
| 重複除去 `sel_dedup` | 初出の盤面だけを残す | `hmwr data dedup --count 100000000` | 約1.08億 |
| 間引き `sel_thin` | 勝率10%未満か90%超を確率0.25で残す | `hmwr data thin --threshold 945 --keep 0.25 --seed 1 --count 100000000` | 約1.55億 |

閾値945は、ラベルの尺度（`cp = 430 × logit(p)`）で勝率10%と90%の境である。
どの群も先頭20億の中から読むので、すべてdlshogiのラベルになる。

### 固定するもの

- 局面数は1億、学習は1周。ステップ数はどの群も同じになる
- 学習のレシピは `dl20_7860M` と同じ。batch 16384、peak_lr 1e-3、λ0.7、seed 0、
  FTクリップ1.0。兄弟群 `rank_tanuki_210M`、検証 `valid_tanuki_dl430_q1`。
  ゼロから学習する
- 対局の条件は[ADR-0214](0214-epochs-bench.md)と同じ。ビルドは両側
  `data/bin/adr0200-himawari`、開始局面は `start_sfens_ply24`、持ち時間は
  10+0.1、hash 64、並列8、裁定2000,8、最大400手。各1,000ペアを指し切る
- 対局は統制との2本。1,000ペアの95%区間は±15前後である

統制と処置は局面の多くを共有する。重複除去は統制の約92%、間引きは非決着圏の
すべてを共有する。共有は交絡ではない。動かしているのは選び方で、局面の出どころ
（同じ一様な標本）は変えていない。

### 解釈の事前登録

対統制のEloを、重複除去でD、間引きでTと書く。「効いた」は点推定が+15以上で、
95%区間の下端が0を超えることとする（[ADR-0214](0214-epochs-bench.md)と同じ基準）。
「害」は点推定が−15以下で、95%区間の上端が0を下回ることとする。

| 結果 | 読み | 次の一手 |
|---|---|---|
| Dが効いた | 重複は予算の無駄で、1億でも測れるほど効く | 付け直しの前に重複を除く。残り58.5億の付け直し（AWS）の入力を重複除去する |
| Dがどちらでもない | 1億では重複の効きは測定幅に隠れる | 害が測定幅に隠れている可能性は残る。付け直しの費用を約1割削れる利点を取り、付け直しの入力を重複除去する |
| Dが害 | 重複（序盤の定番局面の重み）が学習に効いている | 重複を残す |
| Tが効いた | 決着圏が多すぎる。浮いた枠が形勢の揺れる局面へ回って効いた | 残す確率を振る次の測定（0.1と0.5）へ進む。付け直しの前に決着圏を見分ける手段（tanukiの点数で代用できるか）を測る |
| Tがどちらでもない | 決着圏の割合は、この範囲では棋力を左右しない | 間引かない。選び方の次の軸（進行度、教師と現行ネットの食い違い）へ移る |
| Tが害 | 決着圏の局面が学習に要る。ADR-0190の傍証と合う | 間引かない。決着圏の役割（勝ち切り・受けの評価）を盲点ベンチで見る |

DとTの結果は互いに独立に読む。

## 実行

specは `experiments/adr0224-selection-bench.toml` である。選ぶ3本（各4GBの書き出し）、
学習3本（各約0.6時間）、対局2本（各約1.9時間）を順に走らせ、最後に1億のpsvを消す。
合計は約6時間を見込む。学習中に大きなファイルを書かないよう、キューの直列実行に任せる。

`hmwr data thin` の閾値はラベルの尺度に依る。付け直しの前（tanukiの点数しかない
段階）で決着圏を見分けるには別の閾値が要る。本ADRの測定はdlshogiのラベルで
選ぶので、その問題は扱わない。
