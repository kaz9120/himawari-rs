# 0188: 自己生成の世代ループを自給自足の継続学習で回し、初成功を出す

- Status: proposed
- Date: 2026-08-26
- 関連ADR: [0144](0144-selfplay-teacher-loop.md), [0145](0145-continual-learning.md), [0150](0150-rootstrap-evaluation.md), [0185](0185-sibling-ranking-loss.md), [0187](0187-selfplay-gen2.md)

## Context

[ADR-0187](0187-selfplay-gen2.md)は乖離の診断で自前生成を棄却したが、
その基準は問いを取り違えていた（2026-08-26オーナー指摘）。乖離の比較が
答えるのは「いま最良の教師はどれか」であり、「自己生成のループを回せる
状態にできるか」ではない。外部教師を超えるまで検証しない基準は、構造的に
検証を先送りし続ける。

本ADRは目的を置き直す。**外部教師と比べない。自己生成データでの学習を
1回成功させ、「回し続けたらある程度強くなる」状態を作る**。hao 29.9億は
初期値の重みに焼き込まれた資産として扱い、データとしてループへ持ち出さ
ない。プロ棋士の棋譜からBonanza法で立ち上げ、そこからRLで強くした歴史の
構造と同じで、信頼できる外部教師は出発点であって杖ではない。

世代1（−35.7 Elo、[ADR-0144](0144-selfplay-teacher-loop.md)）の失敗は
読み直すと、教師信号の乏しさではなく手続きの問題を指している。

1. **訓練分布と測定分布がずれていた**。生成は平手からランダム8手、
   測定（SPRT）と実戦は定跡24手の開始局面集から始まる。ずれた分布で
   上書きすれば、測定分布の性能を忘れるのは当然である
2. **λ=0.7がscore偏重だった**。scoreは自分の探索値で自己参照的だが、
   指し切った勝敗は外部情報である。RL相では勝敗の比重を上げる余地がある
3. **hao由来validを品質と誤読した**。教師信号を意図的に変えるのだから
   haoから離れるのは当然で、悪化の証拠にならない
   （[ADR-0150](0150-rootstrap-evaluation.md)の帰結を全面適用する）

## 選択肢と比較

### 案A: 自給自足の世代ループ（採用）

生成・学習・検収をすべて自己生成データで回す。1世代のコストを一定に
保ち、世代を刻む。修正は上の3点に集中させる。

### 案B: haoを混ぜて安全側に倒す

忘却対策にはなるが、目的が「ループの成立の検証」である以上、haoに
依存した成功は答えにならない。混合は失敗したときの後退先として残す。

### 案C: 完全オンライン学習

局ごとに更新する形は、探索が量子化済みネットを使う都合と1台構成では
割に合わない。世代粒度の非同期パイプライン（生成と学習の並走）で
近似する。

## Decision

案Aを採る。1世代の手順と条件を固定する。

### 生成（1世代=5,000万局面、一晩）

| 項目 | 値 | 根拠 |
|---|---|---|
| 評価関数 | 現行世代のネット | ループの定義 |
| 開始局面 | `openings/start_sfens_ply32.txt` から一様に引き、ランダム4手 | 訓練分布を測定分布へ合わせる。測定は ply24 の別ファイルを使い、開始局面のリークを避ける |
| 深さ | 8 | 速度と品質の均衡（[ADR-0144](0144-selfplay-teacher-loop.md)）。d10以上は長い裾がある（[ADR-0187](0187-selfplay-gen2.md)） |
| 投了・裁定 | なし | 詰み域を欠かさない |
| 静止化 | しない（`--quiet-plies 0`） | moveフィールドを残し、回帰用の静止化とランキング群を後段で導出する |

生の生成物から2つを導出する。`psv quiet` で回帰用の静止化psv、
`psv rank` でランキング群（[ADR-0185](0185-sibling-ranking-loss.md)の
形式、負例2手）である。

### 学習（継続学習、数時間）

- 前世代のf32チェックポイントから積む（[ADR-0145](0145-continual-learning.md)）
- 窓は直近2世代ぶんの生成データとする（1世代目は1世代ぶん）
- λ=0.5。scoreの自己参照を勝敗の外部情報で薄める
- LRは本学習のpeakの1/10から始める。世代を小さく刻む
- validとbest選択は、その窓の学習範囲外から切り出した20万局面で行う
  （[ADR-0150](0150-rootstrap-evaluation.md)）。hao由来validは「Haoからの
  距離」のテレメトリに格下げし、品質判断に使わない

### 検収と成功の定義

- 世代ごとの検収は、リーグ戦での劣化検知だけを行う（解像度±25〜55、
  [ADR-0150](0150-rootstrap-evaluation.md)の使い分け）。大負けでなければ
  次の世代へ進む
- 成功の判定は、3〜5世代積んだ時点でループ開始時のネット
  `pairrank_2990M_q1_reorder` と既定条件のSPRTを取る。**H1が出たら
  初成功**で、以後は定常運転（[ADR-0187](0187-selfplay-gen2.md)の
  定常運転の節）へ移る
- 1世代の真の利得は数Elo規模の見込みで、既定SPRTの解像度以下である。
  世代ごとにSPRTを要求すると、効いていても判定が出ない

### 調整と撤退

- リーグで大負けした世代は捨て、ノブを1つ動かして作り直す。動かす順は
  λを下げる（0.5→0.4）、LRを半減、窓を広げる、とする。動かしたら本ADRに
  追記する
- 撤退ラインは10世代とする（生成条件の作り直しを含む）。そこまで回して
  累積のSPRTがH0なら停止し、何を試して何が起きたかを記録する

### 計算資源

生成（CPU、一晩4〜5時間）と学習（GPU、2〜3時間）は資源が重ならないので、
世代粒度で並走できる（案Cの近似）。SPSAやSPRTの走行とは時期を区切る。

## 測定・世代台帳

### 世代1（2026-08-26〜27）— H0（−24.2）

| 段階 | 結果 |
|---|---|
| 生成 | 4,767万局面（519,900局、3,246局面/秒、約4時間）。d8でも52万局に1局の長い裾があり、最後の1局は6時間終わらず打ち切った |
| 教師手の修復 | gensfenのmove16がやねうら王符号でなく、教師手の36%が落ちていた。修正（PR #388）と生成済みデータのin-place変換で回復。修復後の群化率95.4% |
| 学習 | 継続学習（lr 1e-4、λ0.5、自前rank群4,280万、2,898ステップ、22分）。self-validは最後まで単調改善（best step 2750）。旧世代1の「step 159で頭打ち」は再現しない |
| 検収SPRT | **−24.2 [−36.1, −12.4]**（3,090局、LLR −2.98でH0。非劣性 elo0=−5 elo1=0） |
| テレメトリ | self valid 0.34269→0.33536（−0.0073）、hao valid 0.48825→0.49027（+0.0020） |

**読み**。学習は自己目的関数の最適化としては成功しており、その方向が
対局の棋力と逆行している。開始局面の整合・λ0.5・self-validの3修正では
旧世代1の−35.7が−24.2へ縮んだに留まる。「1世代で動きすぎ（ドリフト）」と
「目的関数の方向自体が悪い」はまだ分離できていない。

**世代1b: ノブはLRを1/10にする（1e-5）**。Decisionのノブ順はλが先だが、
順序を変えて理由を残す。LRは移動量だけを変えるので符号で仮説を分離できる。
小さく動かして正へ転じるならドリフトで、ループは小刻み積みで成立する。
それでも負なら方向の問題で、λを大きく下げる側へ移る。λ0.5→0.4の一段は
−24.2の規模に対して小さく、切り分けの情報が得られない。

### 世代1b（2026-08-27）— H1（+9.1）

世代1と同一のデータ・目的関数のまま、LRだけ1e-4から1e-5へ下げた。

| 項目 | 値 |
|---|---|
| 学習 | self valid 0.345→0.34496。移動量は世代1（→0.33850）の約1/8 |
| 検収SPRT | **+9.1 [+0.5, +17.7]**（6,176局、LLR +3.00でH1。非劣性 elo0=−5 elo1=0） |

**符号が反転した。世代1の−24.2はドリフト（1世代で動きすぎ）である**。
自己生成の教師が指す方向は、現行の重みの近傍では棋力に対して正で、
移動量を1/10へ抑えるだけで−24.2が+9.1になった。**自己生成データでの
学習が正へ出た初の例になる**。目的関数の側（λ・rank）はこのまま動かさない。

非劣性の採択なので棋力向上はまだ主張しない（[ADR-0163](0163-sprt-hypothesis-choice.md)）。
点推定+9.1は逐次停止の上振れも含む。向上の主張は、世代を積んだ累積を
ループ開始ネットと既定条件で測って行う（Decisionの成功の定義）。

**世代2はこの設定を既定にする**。生成は `rl_g1b`、学習はlr 1e-5、
窓は世代1＋世代2、初期値は `rl_g1b` のチェックポイントとする。

### 世代ごとの検収は非劣性SPRTで行う（2026-08-27変更）

Decisionは世代ごとの検収をリーグ戦としたが、リーグはネット差し替えに
対応していない（バイナリ単位でしか回せない）。`hmwr sprt net` の非劣性を
ゲートに使う。劣化していれば早くH0が出て、良ければH1が出るので、
劣化検知の役は同じに果たせる。

## Consequences

- gensfenに `--openings` を追加した（開始局面の列挙から一様に引く。
  本ADRと同じPR）
- 教師データの置き場が世代ごとに増える（`data/train/rl_g<N>.psv` と
  導出物）。窓から外れた世代は消してよい
- 世代・生成条件・検収結果の台帳を本ADRの測定節が持つ
- 成功したら、[ADR-0187](0187-selfplay-gen2.md)の定常運転の設計
  （固定コスト・節目の全量再学習・検収対局の副産物）がそのまま接続する
