# 0254: 千日手の判定を探索経路内に限り、rootより前との一致は4回目だけにする

- Status: accepted（ノード固定の非劣性でH1。偽の `mate 1` が消えた）
- Date: 2026-11-03
- 関連ADR: [0026](0026-repetition.md), [0088](0088-mate-early-stop.md), [0153](0153-superior-repetition-root-gate.md), [0163](0163-sprt-hypothesis-choice.md), [0186](0186-repetition-scan-cap.md)

## Context

連続王手を受けている局面で、エンジンが読まずに指す。2026-10-29の対AobaNNUE戦では、
87手目以降の3手で評価値が+100000（詰み）と出て、消費は0秒だった。実際には詰みがなく、
相手が別の手を指すと評価値は+1101へ戻った。

この局面を現行で探索すると、深さ1・4ノードで `mate 1` を返して反復を打ち切る。
原因は2つの組み合わせである。

1. 連続王手を受ける側が以前の局面へ戻す手を、探索が「相手の反則負け」と読む。局面の
   2回目で判定し、一致が対局の過去（rootより前）にあっても区別しない。相手は次の手で
   別の手を選べるので、まだ何も決まっていない
2. 詰みが確定したら反復を打ち切る（[ADR-0088](0088-mate-early-stop.md)）。偽の詰みで
   思考時間を丸ごと捨てる

通常の千日手も同じ扱いで、rootより前と一致すると引き分けの値で打ち切る。優等・劣等は
[ADR-0153](0153-superior-repetition-root-gate.md)で探索経路内に限ったが、通常の千日手と
連続王手は「対局ルールそのもの」として残していた。ルールが要るのは4回目であって、
2回目ではない。現行の参照実装も、rootより前との一致を4回目に限っている
（ADR-0153の「参照実装の扱い」）。

## 選択肢と比較

### 案A: 詰みの打ち切りをやめる

偽の詰みの値は残るので、悪い手を選ぶ問題は直らない。

### 案B: 連続王手だけを探索経路内に限る

通常の千日手の偽の引き分けが残る。判定の条件が3種類に分かれる。

### 案C: すべての判定を探索経路内に限り、4回目だけ例外にする（採用）

判定の条件が1つになる。優等・劣等の条件（`i < ply`）と揃う。

## Decision

案Cを採る。`repetition_state(ply)` は、一致した局面が探索経路内（距離 `i < ply`）に
あるときだけ千日手を返す。rootより前かrootそのものとの一致は、今の局面が対局の4回目で
あるときだけ返す。裁定用の `repetition_state_all` は変えない。

変わるのは、探索の中で対局の過去の局面へ戻るノードだけである。一致のない局面の探索木は
変わらない。

### 合格の条件

- Eloの判定: ノード固定（`--nodes 100000`）の非劣性（elo0=−5、elo1=0）。価値は偽の詰みと
  偽の引き分けで思考を捨てなくなることで、対局の開始局面集では発動が少なく、Eloでは
  差を測りにくい（ADR-0163）
- Elo以外の条件: 上の局面で `mate 1` が消え、実際の局面の評価値を返すこと。単体テストで
  4回目の判定を保つこと
- 採否: 両方を満たしたときだけ入れる

### 事前登録

- 非劣性でH1なら入れる
- H0なら、rootより前との一致を引き分け寄りに読む案（値をdraw値と評価値の間にする）を
  起こす。偽の詰みだけを止める案Bへ戻すことも検討する

## SPRT

ノード固定（`--nodes 100000`）、elo0=−5、elo1=0で測った。比較元はorigin/mainの `7aa05eb` である。

| 対局数 | W-D-L | Elo [95%CI] | LLR | 切れ負け | 判定 |
|---|---|---|---|---|---|
| 18218 | 8834-539-8845 | −0.2 [−4.1, +3.7] | +2.86 | 0 | H1 |

## Consequences

- 千日手を打開できる側が、4回目まで打開を先送りすることがある。探索経路内の判定は
  残るので、1周先の一致は読める
- 評価値が負けの側が、rootより前の局面へ戻す手を「引き分け」と読まなくなる
