# 0255: 王手の延長を根の深さの2倍の手数までにする

- Status: proposed
- Date: 2026-11-04
- 関連ADR: [0163](0163-sprt-hypothesis-choice.md), [0211](0211-check-extension-see.md), [0233](0233-check-extension-hanging.md)

## Context

Issue #815の局面（`openings/profile_late_positions.txt`）で、1反復が終わらない局面がある。
局面12は深さ16が106万ノードで終わるのに、深さ17が7000万ノードを超えても終わらない。
評価値はどれも−4000より悪い、王手の応酬が続く局面である。

局面12を4000万ノード読んだときの手数ごとのノード数を数えると、深さ17の探索が
手数の上限128まで届いていた。

| 手数 | 探索ノード | うち王手を受けている割合 |
|---|---|---|
| 60 | 28,538 | 71% |
| 100 | 79,153 | 68% |
| 120 | 1,097,202 | 71% |
| 128 | 4,550,899 | 82% |

王手は1手延長するので、王手と応手の連鎖では深さが2手で1しか減らない。応手も王手なら
減らない。上限128に着くと静的評価を返すだけなので、ここで使うノードは読みの質に
つながらない。

## 選択肢と比較

### 案A: singular延長にも同じ上限を入れる

局面4・10・12で試すと、王手の延長に上限を入れた場合より良くならなかった。動かす変数を
増やさないために入れない。

### 案B: 上限を根の深さの3倍にする

singular延長にも同じ上限を入れて試すと、局面4は4.5秒かかり、局面12は深さ16で止まった。

### 案C: 王手の延長を手数が根の深さの2倍未満のときに限る（採用）

局面4が0.9秒で終わる。2倍という値がこの評価関数で害を出さないかは、下のSPRTで確かめる。

## Decision

案Cを採る。singularの判定が付いたTT手の延長は変えない。

20秒を上限に `go depth 18` で12局面を読んだ。主な変化は次のとおりで、局面10と12は解消しない。
局面3と11は少し遅くなり（0.5→0.8秒、0.7→1.0秒）、ほかの局面は大差がない。

| 局面 | 変更前 | 変更後 |
|---|---|---|
| 4 | 20秒で深さ17、cp −5561 | 0.9秒で深さ18、cp −28000 |
| 6 | 2.0秒 | 1.3秒 |
| 10 | 20秒で深さ17 | 20秒で深さ17（解消しない） |
| 12 | 20秒で深さ16 | 20秒で深さ17（解消しない） |

組み込みの4局面の深さ16では、局面3だけノード数が変わる（395,597→368,472）。

### 合格の条件

- Eloの判定: ノード固定（`--nodes 100000`）の非劣性（elo0=−5、elo1=0）。発動するのは
  手数が根の深さの2倍以上の王手だけである。価値は1反復が終わらない局面を減らすことで、
  Eloの向上は主張しない
- Elo以外の条件: 上の局面4が1秒前後で深さ18へ届くこと
- 採否: 両方を満たしたときだけ入れる

### 事前登録

- 非劣性でH1なら入れる。局面10・12が残るので、#815は閉じない
- H0なら入れず、上限を根の深さの3倍にした案は試さず棄却する。3倍では局面4・12の浪費が
  残るからである

## Consequences

- 根から遠い王手の連鎖の詰みは読みにくくなる
