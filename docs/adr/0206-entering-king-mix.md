# 0206: 入玉5億局面を教師へ混ぜ、入玉局面の弱さを埋める

- Status: proposed
- Date: 2026-09-15
- 関連ADR: [0030](0030-nyugyoku-declaration.md), [0135](0135-teacher-data-3b.md), [0185](0185-sibling-ranking-loss.md), [0190](0190-selfplay-decided-thinning.md), [0192](0192-tanuki2024-teacher.md), [0199](0199-roadmap-inventory.md)

## Context

教師データの入玉局面は薄い（hao_depth9で1.65%、[ADR-0190](0190-selfplay-decided-thinning.md)）。
floodgateの負け649局のうち入玉宣言負けが13局あり（[ADR-0199](0199-roadmap-inventory.md)の
訂正後の集計）、負けの2%を占める。持将棋のルールが2028年に24点法へ
変わる見込みで（ROADMAPの制約）、入玉の強さは選手権でも効く。

公開データに入玉専用の教師がある。nodchip/shogi_suisho5_depth9_entering_king
はMITライセンスで約5億局面。floodgateの2015〜2024年から入玉局面を集め、
Suisho5のdepth 9でラベルを付けたものである。生データは取得済み
（[DATASETS.md](../DATASETS.md)）。

「計算を積まず、測って直す」方針（ADR-0199の追記）に沿う。学習は3億の
測定台で3時間、対局で2時間である。

## 仮説

**入玉局面の教師を混ぜると、入玉局面の指し手が良くなり、通常の局面では
弱くならない**。

## 測定の設計

### 動かす変数

混合の比率だけ。統制は3億の測定台（hao、`pairrank_300M_q1`、ゼロから
学習済み）で、処置は同じ3億に入玉局面を足してゼロから学習する。

| 条件 | 入玉の局面数 | 比率 |
|---|---|---|
| 統制 `pairrank_300M_q1` | 0 | 0% |
| 処置A `ekmix6_300M` | 1,800万 | 6%（本学習の78.6億に5億を混ぜたときと同じ） |
| 処置B `ekmix20_300M` | 6,000万 | 20%（効きが比率で伸びるかを見る） |

### 固定するもの

- 入玉データは全体をシャッフル（seed 1）してから先頭を取り、1手静止化
  （[ADR-0136](0136-quiet-teacher-positions.md)）。静止化の評価関数は現行
  ネット。3億側は `train_300M_q1.psv` をそのまま使い、2つをシャッフルで
  混ぜる
- 兄弟群は統制と同じ `rank_300M_100M.rankpsv`（hao由来）。入玉側からは
  作らない。ランキング損失の分布を動かさないため
- 学習は統制と同じレシピ（ゼロから1エポック、batch 16384、peak_lr 1e-3、
  λ0.7、seed 0）。検証は `valid_385M_q1`
- 対局は2本。通常の開始局面（`start_sfens_ply24`）と、入玉の開始局面
  （入玉データから40手目以降を2,000局面抜き出す）。各500ペア固定

### 読み方の事前登録

| 通常局面（対統制） | 入玉局面（対統制） | 読み |
|---|---|---|
| −10以上（下端が−20を超える） | +15以上 | 混合は効く。本学習の次回のゼロからの学習で5億を混ぜる |
| −10以上 | ±15以内 | 効かない。入玉の弱さは教師の量では埋まらない。閉じる |
| −10未満 | 問わず | 通常局面を損なう。比率を下げても損なうなら閉じる |

処置Aと処置Bの差は、比率の傾きとして読む。Bで効いてAで効かなければ、
本学習で5億では足りない（もっと要る）と分かる。

## Consequences

- 効けば、次のゼロからの本学習（50時間）のデータに5億を加える。継続学習
  で混ぜる案は、[ADR-0201](0201-loop-recipe.md)の1回きりの+15と交絡するので
  取らない
- 入玉の開始局面集（`openings/entering_king_ply40.txt`）が増える。入玉の
  強さを測る物差しとして残す
