# 0016: 王手・pin・合法性判定

- Status: accepted
- Date: 2026-07-17
- 関連ADR: [0011](0011-slider-effect-gen.md), [0014](0014-position-structure.md)

## Context

指し手の合法性（自玉を王手に晒さない、打ち歩詰めでない）を
どの層でどう保証するかは、指し手生成の構造を決める。全生成手に
完全な合法性検査をかけると重く、かといって探索に非合法手が
混ざると壊滅的なバグになる。王手されているかどうかで生成戦略を
分けるのが定石で、その基盤となるcheckers/blockers/pinnersは
ADR-0014でStateInfoに置くと決めてある。

## 選択肢と比較

### 案A: 完全合法生成

生成の時点で全手が合法であることを保証する。呼び出し側は単純に
なるが、生成ループの内側で毎手pin判定と玉の安全確認が入る。

### 案B: 擬似合法生成＋O(1)のis_legalフィルタ

自殺手の可能性がある手は3種類しかない。玉を動かす手（移動先が
敵利きにある）、pinされた駒を動かす手（pinの筋から外れる）、
そして打ち歩詰めの歩打ちである。blockers_for_kingが差分計算
済みなら、pin検査は「fromがblockersに含まれるか＋from/to/玉の
共線判定」の数命令で済む。Stockfish・やねうら王と同型。
駒打ちはpinと無関係なので、歩打ち以外は常に合法になる。

## Decision

案Bを採用する。構成は次のとおり。

### 生成戦略の分岐

- 王手されていないとき: 擬似合法生成＋`is_legal` フィルタ。
  検査対象は玉移動とpin駒移動のみで、それ以外は無検査で合法
- 王手されているとき: 王手回避（evasions）専用生成。両王手なら
  玉移動のみ、単王手なら「玉移動・王手駒の捕獲・合い駒（遠隔
  王手のみ。合い駒には駒打ちを含む）」を生成し、`is_legal` を通す

### checkers / blockers / pinners

do_moveで毎回再計算する（ADR-0014）。計算は両玉分行う。
自玉のblockersはis_legalのpin検査に、敵玉のblockersは
gives_checkの開き王手判定に使う。アルゴリズムは、玉と同じ
筋・段・斜めにいる敵の遠距離駒（sniper）ごとに、間の駒が
ちょうど1枚ならその駒をblockersに、sniperをpinnersに入れる。

### is_legal（擬似合法手に対するO(1)検査）

1. 玉移動: 移動先に敵の利きがあれば非合法。占有から玉を除いて
   利きを判定する（遠距離駒の「貫通」を正しく扱うため）
2. pin駒の移動: `from ∈ blockers_for_king` のとき、from・to・玉が
   共線でなければ非合法（line判定テーブル）
3. 歩打ち: 打ち歩詰め検査（下記）。それ以外の駒打ちは常に合法

### 打ち歩詰め検査

対象は「敵玉の直前への歩打ちで、かつ王手になる手」だけ。
このときのみ次を確認し、両方とも不可能なら詰み＝非合法とする。

1. 敵が歩を取れるか。取り手候補（玉以外）が全てpinされていないか
2. 敵玉に逃げ場があるか。玉の移動候補それぞれについて、
   歩打ち後の占有で敵利きがないマスが存在するか

稀な経路なので速度より正しさを優先し、素直に書く。
perftのエッジケースSFEN集（ADR-0006）に打ち歩詰め局面を入れて検証する。

### gives_check（王手になる手かのO(1)判定）

- 直接王手: `to ∈ check_squares[移動後の駒種]`（StateInfoに保持、ADR-0014）
- 開き王手: `from ∈ 敵玉のblockers` かつ from・to・敵玉が非共線
- 駒打ちは直接王手のみ

## Consequences

- 生成ループの内側から合法性検査がほぼ消え、検査は玉移動・
  pin駒・歩打ちの3経路に局所化される
- 正しさの担保は二重にする。property testで「擬似合法＋is_legal」の
  結果を素朴な全数合法判定（do_moveして自玉の利きを調べて戻す）と
  突き合わせ、perftで公開値と照合する
- 打ち歩詰め検査は将棋固有ルールで最もバグが出やすい箇所になる。
  検査経路を1関数に閉じ込め、詰将棋由来のエッジケースを
  単体テストに蓄積する
- 王手放置・自殺手が探索に混入しない保証はis_legalの正しさに
  一点集中する。ここのテスト密度を最優先にする
