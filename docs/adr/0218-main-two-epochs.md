# 0218: 本学習の78.5億を2周し、1周のネットとSPRTで比べる

- Status: proposed
- Date: 2026-09-21
- 関連ADR: [0159](0159-ft-width-1024.md), [0185](0185-sibling-ranking-loss.md), [0192](0192-tanuki2024-teacher.md), [0201](0201-loop-recipe.md), [0212](0212-tanuki-bench-mix.md), [0214](0214-epochs-bench.md), [0217](0217-sprt-pass-cap.md)

## Context

[ADR-0214](0214-epochs-bench.md)で、3億の測定台では同じデータの2周が
1周より+32.2 [+17.7, +46.9]強く、同じステップ数を新規の3億へ回すと
+70.4だった。事前登録の読みは「繰り返しは新規データに劣るので、本学習の
2周は設計しない」である。

ただし本学習（[ADR-0192](0192-tanuki2024-teacher.md)、tanuki 2024の78.5億）は
同じ系列の新規データを使い切っている。実際の選択肢は「2周するか、しないか」で、
「2周か新規か」ではない。新規データが無いからこそ、2周で効くならやる価値が
ある（オーナー判断、2026-09-21）。棋力の改善が止まっている中で、100時間を
効く見込みのある投資に使う。

2周の効きは規模で薄まる見込みがある。3億の+32.2には、cosineの減衰が2倍の
長さになった「追加の最適化」の効きが含まれる。78.5億×1周は479,372ステップで
最適化がより進んでいるので、繰り返しの効きは3億より小さいと予想する。
どれだけ残るかは測るまで分からない。

## 仮説

**78.5億を2周したネットは、1周のネットより強い**。

## 測定の設計

### 動かす変数

エポック数だけを1から2にする。cosineの減衰は2周分の長さになる
（`total_steps = epochs × steps_per_epoch`）。バッチの並びは種とエポックで
決まるので、2周目は1周目と別の順で回る（[ADR-0159](0159-ft-width-1024.md)）。

### 固定するもの

- データは本学習と同じ。`train_7860M_q1`（静止化済み、シャッフル済み）、
  兄弟群 `rank_tanuki_210M`、検証 `valid_tanuki_q1`
- レシピは本学習と同じ。batch 16384、peak_lr 1e-3、λ0.7、seed 0、
  FTクリップ1.0。ゼロから学習する
- 比較は1周のネット `pairrank_7860M_q1` 対2周のネット `main2ep_7860M`。
  同一ビルドのネット差し替え（`hmwr sprt net`）で、どちらも並べ替え
  （ADR-0168）を施さない素のネットにする。並べ替えは速度だけを変える
- SPRTは既定（elo0=0、elo1=5、10+0.1）。上限は[ADR-0217](0217-sprt-pass-cap.md)の
  10,000ペアで、判定に至らなければ見送り

現行の対局用ネット `rl_e1d8_reorder` は、1周のネットに自己生成4,700万の
継続学習（[ADR-0201](0201-loop-recipe.md)、+20.2）と並べ替えを足したもので
ある。本ADRは継続学習の前の土台どうしを比べる。土台で勝てば、継続学習を
2周のネットにも施して現行と比べる工程が次に来る。

### 読み方の事前登録

| 判定 | 読み | 次の一手 |
|---|---|---|
| H1 | 78.5億でも繰り返しが効く。3億の+32.2の一部が残った | 2周のネットへADR-0201の継続学習を施し、現行 `rl_e1d8_reorder` と既定SPRTで比べる（次のADR）。勝てば切り替える |
| H0 | 繰り返しは規模で消え、2周は害になる | 閉じる。本学習は1周のまま。量を足す先はラベルの付け直し（ADR-0215）と別系列の教師に絞る |
| 見送り（10,000ペアで判定に至らず） | 効きは±2.5の中で、100時間に見合わない | 閉じる。同上 |

## 実行

[ADR-0209](0209-workflow-layers.md)の実験キューで走らせる。specは
`experiments/adr0218-main-two-epochs.toml` で、学習1本とSPRT1本である。

学習は約101時間（1周の50.6時間の倍、48kサンプル/秒）。落ちたら同じ
コマンドでエポック内の位置から続く（[ADR-0159](0159-ft-width-1024.md)）。
SPRTは判定まで、長くても上限の約20時間。キューの順は
ADR-0215→ADR-0216→本ADRになる。

学習中はMPSが占有される。CPUの対局（SPRT）は並行できるが、キューは
直列なので他の実験は待つ。約5日、キューがこの1本に使われることを
受け入れる（オーナー判断）。

## Consequences

- 効いた場合、本学習の標準が2周になり、以後の本学習は約100時間かかる。
  ラベルの付け直しや別系列の教師の実験が効いたときも、本学習は2周で
  回すことになる
- 効かなくても、「規模で繰り返しの効きが消えるか」の答えが1本残る。
  3億の測定台の結果を本学習へ外挿するときの割引率の材料になる
- 学習の途中で `training/checkpoints/main2ep_7860M/` が128MB×数本増える
