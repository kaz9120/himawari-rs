# 0045: 利き塔の除去

- Status: accepted（2026-07-21オーナー承認）
- Date: 2026-07-21
- 関連ADR: [0034](0034-nnue-architecture.md), [0044](0044-p7-feature-experiments.md)

## Context

ADR-0044のP7特徴量実験で、利き塔（EFFECT_IN=800, EFFECT_OUT=32）の
効果を検証した。結果:

- valid loss: 利き塔ありの方が0.005低い（0.526 vs 0.531）
- 棋力: 利き塔なしの方が+70〜100 Elo強い（110ペア220局時点）
- NPS: 利き塔の計算コストは約-40%

valid lossの改善が棋力に変換されない。利き塔の32次元が
隠れ層32ノードの容量を圧迫している可能性がある。

## Decision

利き塔をコードベースから除去する。

- NNUE構成: HalfKP 256×2 = 512次元 → 隠れ層32-32-1
- .hmwrフォーマット: VERSION=2。ef_w/ef_bを除去
- NPS: 約+40%の改善

将来、玉ライン特徴など別形式の第2塔を追加する場合は
別ADRで再導入する。

## Consequences

- NPS約+40%の改善。同一持ち時間でより深く探索できる
- 既存の.hmwr（VERSION=1）は新コードで読めなくなる。
  新しいネットを学習する必要がある
- CONCAT=512（旧544）で隠れ層の入力が減り、パラメータ総数も
  約1%減少する
