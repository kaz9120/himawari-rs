# 0149: 実験の実行とログを規約で固定する

- Status: proposed
- Date: 2026-08-08
- 関連ADR: [0028](0028-pruning-extensions.md), [0053](0053-docs-structure.md), [0081](0081-portability.md), [0122](0122-tooling-language-split.md), [0123](0123-stop-and-resume.md)

## Context

**毎回コマンドを組み立て直している。** 2026-08-08の1日で手打ちした回数を
数えると、ネット比較のSPRTが4回、ネットの検証損失の測定が6回、教師局面の
静止化が5回、本番の学習が3回あった。どれも引数が10個前後あり、そのたびに
条件を思い出して並べている。

**打ち間違いが測定を壊す。** [ADR-0028](0028-pruning-extensions.md)の既定条件は
7個の引数で表される。1つ違えば別の条件の測定になるが、結果の数字は同じ形で
出るので気づかない。`scripts/sprt.sh` はこれを固定するために作ったが、
**バイナリ2つを比べる形しか持っていない**。評価関数だけを差し替える比較
（[ADR-0136](0136-quiet-teacher-positions.md)・[ADR-0138](0138-ft-i8-quantization.md)で
多用した）はスクリプトの外にあり、`--bopt EvalFile=...` を手で書いていた。

**ログの置き場が決まっていない。** `data/` 直下に21本たまっており、名前は
`sprt-adr0136-net.log`・`train-q0.log`・`quiet-q16.log`・`book-adr0146.log` と
規則がない。リダイレクト先もコマンドを打つたびに決めている。

[ADR-0053](0053-docs-structure.md)は `data/` の配置を決めているが、ログには
触れていない。[ADR-0122](0122-tooling-language-split.md)は言語の役割分担までで、
どの操作をスクリプトにするかは決めていない。

## 選択肢と比較

### 案A: Makefileでまとめる

`make sprt-net BASE=... CAND=...` のように書ける。ターゲット一覧が
`make help` で引ける利点がある。ただし `scripts/` が既にあり、Makefileは
その呼び出しを並べるだけになる。**同じ操作の入口が2つできる。**
GNU makeとBSD makeの差も踏み台になる（[ADR-0081](0081-portability.md)）。

### 案B: 統一エントリポイントを1本置く

`scripts/run.sh <サブコマンド>` に集める。入口が1つで済むが、サブコマンドが
増えるほど1本が肥大する。`sprt.sh` などの既存スクリプトを吸収するか
並存させるかの判断も要る。

### 案C: 操作ごとにスクリプトを足し、共通部分を env.sh へ寄せる

いまの `scripts/` の作りをそのまま延長する。1操作1ファイルで、`-h` に使い方を
書く。ログの置き場と命名は `env.sh` の共通関数で決める。

## Decision

**案Cを採る。**

理由は入口を増やさないことである。`scripts/*.sh` を叩くという既存の慣習が
あり、そこへ足すのが最も学習コストが小さい。Makefileや統一エントリを置くと、
同じ操作に2つの呼び方ができる。

### ログの置き場

**`data/logs/<名前>.log` に置く。** `data/` はgitignore済みである
（[ADR-0053](0053-docs-structure.md)）。

- 名前は呼び出し側が渡す実験名をそのまま使う。`data/logs/adr0136-net.log` の形
- **追記する。** 停止と再開（[ADR-0123](0123-stop-and-resume.md)）で同じ実験を
  複数回に分けて走らせるため、上書きすると前半が消える
- スクリプトは端末にも同じ内容を流す。`tee -a` を使う

`env.sh` に `log_path <名前>` を置き、ディレクトリの作成もそこで行う。
**リダイレクト先を呼び出し側で決めない。**

### 足すスクリプト

| スクリプト | 操作 | 今日の手打ち回数 |
|---|---|---|
| `sprt-net.sh` | 同じビルドで評価関数だけ差し替えて測る | 4 |
| `eval-net.sh` | ネットの検証損失を測る（複数の検証集合を並べる） | 6 |
| `quiet.sh` | 教師局面をqsearchの静止局面へ置き換える | 5 |
| `train-net.sh` | 本番規模の学習を回す | 3 |

**既定を持たせる。** `sprt-net.sh` は [ADR-0028](0028-pruning-extensions.md)の
既定条件を `env.sh` から取る。`quiet.sh` は `--max-plies 1` と現行の評価関数を
既定にする（[ADR-0136](0136-quiet-teacher-positions.md)の結論）。`train-net.sh` は
FTクリップ1.0とmmapを既定にする（[ADR-0138](0138-ft-i8-quantization.md)・
[ADR-0135](0135-teacher-data-3b.md)）。

**既定を変えたら、その理由がADRに残っている状態を保つ。** 既定値はADRの結論を
実行可能な形にしたものである。

### 引数の順序を揃える

どのスクリプトも「入力 → 出力 → 名前」の順で位置引数を取り、条件は環境変数で
渡す。`sprt.sh` の `<baseline> <candidate> <名前>` に合わせる。

## 棚卸し（2026-08-08）

スクリプトを足すのと同時に、既存を数えた。**足す前に、要らないものが
ないかを見る。**

`scripts/*.sh` と `scripts/*.py` の15本すべてで `-h` が使い方を返す
（`env.sh` はsource専用なので対象外）。壊れているものはなかった。
`release-net.sh` がフォーマット版5を読めなかった前例（2026-08-08）があるので、
動くことは都度確かめる。

**`league-summary.py` だけが文書のどこからも参照されていない。**
[ADR-0128](0128-round-robin-league.md)のリーグ戦を支える道具で、仕組み自体は
acceptedである。スクリプトが不要なのではなく、ADRに名前が出ていない。
本ADRからの言及で参照を張る。

**消すべきスクリプトはなかった。** `fetch-dataset.sh` はhao_depth9を使い
切ったので出番が減るが、`data/` を消して作り直すときに要る
（[DATASETS.md](../DATASETS.md)が手順として参照している）。

### 使う機会のない既定を持たせない

`eval-net.sh` の検証集合は、当初「非静止と静止化の2つを並べる」を既定に
していた。**これは誤りである。** [ADR-0136](0136-quiet-teacher-positions.md)が
決着し、現行の教師も検証集合も静止化済みになった。以後の学習で非静止validを
見る場面はない。

既定は静止化した検証集合1つに絞り、土俵を跨ぐ比較は環境変数で明示的に
渡す形にした。**スクリプトの既定は「いま使う条件」であって、「かつて
使った条件」ではない。**

## Consequences

- スクリプトが4本増える。`scripts/` は16本から20本になる
- **既定値がスクリプトへ移る。** ADRを読まずに実行できる代わりに、既定を
  変えたときにADRとの対応が切れる危険がある。既定値のそばにADR番号を書く
- 既存のログ21本は `data/logs/` へ移す。gitignore対象なので履歴には影響しない
- Makefileを置かない判断は、入口が1つで足りるうちのものである。スクリプトが
  30本を超えて一覧性が問題になったら、`scripts/help.sh` のような索引を検討する
